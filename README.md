# NYC Motor Vehicle Collision Analysis

## Overview

This project analyzes NYC Motor Vehicle Collisions data with a focus on Manhattan road safety.

Using Python and NYC Open Data, the analysis explores collision patterns, contributing factors, and crash timing to identify potential safety risks and support data-driven transportation recommendations.

## Business Question

What patterns in Manhattan motor vehicle collisions can help identify road-safety risks and inform targeted safety interventions?

## Analysis

The project explores:

- Common contributing factors in Manhattan collisions
- Collision frequency by time of day
- Crash patterns and potential safety risks
- Opportunities for actionable road-safety recommendations

## Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- NYC Open Data API

## Data Source

NYC Open Data — Motor Vehicle Collisions: Crashes
